# OPAIJA Style Guide

This is the working style lock for future Opaija characters and generated media.

## Core Visual Identity

Opaija is a `2D Caribbean anime model-sheet style`: clean anime readability, African/Caribbean facial features, island streetwear, Kalenda/Calinda combat culture, and bright Trinidad/Tobago energy. The production look should read as a hand-drawn animated series, not pseudo-3D, plastic, painterly, photoreal, or generic AI fantasy art.

For teaser trailers and high-action clips, use the premium cinematic action finish from `docs/OPAIJA_TRAILER_QUALITY_REFERENCE.md`: dark charcoal/brown environments, controlled gold/orange Opaija energy, heavy contrast, warm rim light, glowing staff effects, flying debris, cracked ground, kinetic low-angle camera, and sharp anime/comic finish. This trailer finish must enhance, not replace, the approved character bible sheets.

## Character Face Rules

- Rounded chins, not pointed V-shaped generic anime chins.
- Full lips with character-specific shape.
- Broad African/Caribbean nose structures with individual variation.
- Warm, expressive eyes and readable expressions.
- Hair should be brandable: locs, wraps, beads, shells, braid patterns, island color accents, and culture-specific silhouettes.

## Model Sheet Standard

Every recurring character needs:

- Turnaround views
- Action pose
- Relaxed pose
- Casual pose
- Head angles
- Expressions
- Key details and gear
- Color palette
- Profile
- Scale and notes
- Signature line
- Seedance prompt
- Remotion/editing notes

## Brand Memory Prompt

Use this prompt core for all new characters:

```text
Create in the locked OPAIJA 2D Caribbean anime model-sheet style: rounded chin, full lips, broad African/Caribbean nose language, expressive warm eyes, clean black ink linework, bright island energy, modern Caribbean streetwear fused with Kalenda/Calinda and Carnival-inspired details, controlled gold/orange/red/teal/cream accents, flat cel-shaded 2D animated-series clarity, duplicable proportions for Seedance and Remotion. For trailer shots, use premium dark cinematic Trini anime action quality: gold/orange energy, rim lighting, debris, cracked ground, kinetic low-angle martial poses, and expensive franchise-ready contrast.
```

## Never Drift Into

- Generic fantasy armor
- Pseudo-3D, plastic, painterly, photoreal, or overly glossy AI art
- Washed-out muted palettes
- Thin generic anime facial features
- Random symbols that fight the Opaija mark system
- Non-specific "island" styling without Trinidad/Tobago or Caribbean cultural grounding
